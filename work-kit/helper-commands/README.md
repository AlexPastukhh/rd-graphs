# RDG Chat Launcher Commands

Status: RDG-owned source and deterministic transport projection. This is not an RDG lens definition, a new graph type, or a live runtime API. It does not install or publish lenses.

**Source:** [commands.json](commands.json) is the editable source of truth for chat insertion messages. Each command has stable id, kind, title, description, typed \`lensRef\` and exact \`insertText\`. The text is owned by RDG, not generated by OBS. Future non-lens kinds require an explicit schema change; v1 is lens-launcher only.

**Build:** \`python3 -B tools/rdg-helper-commands.py\` regenerates [catalog.json](catalog.json), the complete read-only transport manifest with deterministic catalogRevision (SHA-256 of normalized commands). \`--check\` verifies exact generated bytes; tests: \`python3 -B tests/rdg-helper-commands.test.py\`. The one-off \`--init\` was used for initial authoring and must not be run over an existing source. To edit, update commands.json and rebuild.

**Coverage:** v1 has exactly one command for each supported \`rdg-decision-v1\` lens identity found in the current local \`tools/rdg-agent-lenses/catalog.json\`: 21 including operate and develop. The builder checks role, profile and coverage from identity metadata; it deliberately neither reads nor requires the full freeform Markdown sources or source maps. The source metadata is not a replacement for live Agent verification; compare with a fresh authorized \`rdg-agent.py lenses\` before claiming exact live coverage.

**Distribution:** once merged into rd-graphs main, an HTTPS GET of \`work-kit/helper-commands/catalog.json\` from the public repository provides the entire command list in a single response. A client must accept only \`complete=true\` and the versioned shape, replacing its local cache only after full validation. No ambient fetch or per-lens network calls. The server-side RDG API still provides the full actual lens definition when ChatGPT handles the inserted command.

**Security/limits:** No credentials, machine grants, private context content, automatic command execution or Graph writes belong in this manifest. The command text contains a conceptual Agent invocation with a placeholder for *an existing authorized context*, never a context value or token. A browser consumer must not invent/obtain its own authorization. The public GitHub file and live RDG runtime are independent release/readback surfaces; new source revisions are not live until merged/published. Do not interpret a static catalog as proof that a lens Graph is published or currently readable.

The contents of the RDG lens Graph and the full methodology remain owned by RDG, not this manifest. The initial source was populated by a one-time identity-aware bootstrap, after which changes to \`insertText\` are made in commands.json only.
