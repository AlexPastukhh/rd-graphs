# RDG — практические Use Cases

> **СТАТУС: ДЕЙСТВУЮЩИЙ ЛОКАЛЬНЫЙ РЕЕСТР.** Ситуации и проверяемые результаты, а не полное описание функций или инструкции по установке Windows. Точные поля и нормы принадлежат [контракту](../guides/RDG-ACTIVE-CONTRACT.md), [API](../guides/RDG-DECISION-V1-CONTRACT.md), [регламенту](../guides/RDG-OPERATIONS.md) и [текущему состоянию](../guides/RDG-CURRENT-STATE.md).

Начинайте **с нужной ситуации**, не читайте весь реестр подряд. Общие Docker/GitHub/CI/Windows и AI-authorization правила принадлежат контейнерным `UC-CONT-002`/`UC-CONT-003` и [его README](/workspace/repo/README.md); они **не копируются** сюда. Этот реестр не содержит отдельного сценария обновления Windows: позднее его объяснят общие фундаментальные UC. Для уже работающего Viewer и ИИ ниже достаточно прикладных сценариев.
