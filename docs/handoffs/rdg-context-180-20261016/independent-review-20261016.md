## Подтверждённая находка P-01 (CURRENT, исправлена)

`tools/rdg-state.js` допускал `contextUses` непосредственно на корне `node.canonBlock`, но `uses()` обходил только graph/node/canon case. Минимальная отдельная проба дала `validate=true`, `collect.fields=[]`, `incomplete=[]` при реально указанном usage; это скрытая потеря полей и ложная полнота. Нормативный список мест использования в §15 допускает graph, node, case, но не корень блока. Исправление: валидатор теперь явно отвергает неподдерживаемое размещение; Python `has_state` распознаёт ошибочный metadata shape, чтобы локальный writer не обходил валидатор; новый негативный/позитивный тест проверяет отказ и корректное `recommended` case. Обновлена нормативная строка документации и embedded Viewer source. Не расширялся формат данных или scope ответов.
