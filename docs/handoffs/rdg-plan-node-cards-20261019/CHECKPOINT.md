# Viewer 2.2.5 — карточки графа в плане и переход к объявлению

2026-10-19. Выполнены запросы пользователя о карточках существующих узлов,
канонах/QRPE Actions и переходе к месту первого объявления вместо личного R-графа.

План меняет явное размещение ссылки на существующий R/Action. Создание/редактирование
перенесены на вкладку «Граф» с отдельным статусом и точным повтором запроса.
Цель показывает связанные Actions, включая продолжения из других прочитанных файлов.
Каноны и открытые QRPE видны сразу. Контекстный показ не размещает и не выбирает Action.
Самостоятельный Action показывает связь с целью; неразмещённая цель помечена контекстом.

Переход разрешает ownerRef проекции, проверяет identitySpace и тип узла, затем
открывает родительскую волну INTRODUCES для R или волну DRIVES/OPTION_FOR для Action.
Узел выделяется и центрируется; личный граф не подставляется при отсутствии владельца.
Правка варианта с уже существующим размещением сохраняет фактический graphRef/stepId.
Новый Helper размещает только из уже прочитанных источников и не меняет графы;
коллизия локального stepId не затирает другую ссылку. Запись графа остаётся привязана
к настроенному файлу. Старый Helper совместим с размещением из своего файла.

Финальная регрессия: 70 Node PASS, 0 FAIL, 3 условных live-Helper SKIP.
Helper: 14 Python PASS; cross-owner GUI и размещение существующих узлов: 2 PASS.
Chromium: каноны/QRPE, варианты в продолжении, исходное объявление R, Actions из
обоих файлов, отдельный редактор графа, мобильный экран — PASS, pageerrors=0.
Полный граф: browser PASS, 4 снимка. Системный picker имитируется; Windows не проверен.
