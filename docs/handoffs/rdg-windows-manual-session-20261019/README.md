# Ручная Windows-проверка Viewer 2.2.1

Отдельные временные синтетические Graph/Plan owners; настоящие графы не меняются.
Сессия файловая, без сервера или туннеля; срок 30 минут от запуска. После остановки descriptor inactive.
Пользователь обновляет свой Viewer и выбирает session через native picker. latest-view.json — проверяемые результаты, не новый project owner.
