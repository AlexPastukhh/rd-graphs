# Сквозной пакет — Candidate

Поручение пользователя: выполнять план крупным связным пакетом для ранней проверки целого.
Технический рабочий набор: одно выполнение Action-instance; явный отзыв через существующий writer и журнал с отдельным grant и сохранением политик/child dispositions; удобные place/unplace операции Plan owner; R references; read-only будущее/история и HTML/Markdown из тех же данных. Без новых сервисов и миграции пользовательских графов.

Проверка: A1 без размещения, выполнен A1 → отзыв A1 → выбор/выполнение A2 той же R; R и Actions размещаются по времени/порядку без выбора; выполненное исчезает из будущего с теми же ID; старое выполнение не теряется после правки; deny/CAS/replay/recovery; отсутствие ложных промежуточных результатов; старые snapshots читаются; неподдержанный Gendocen context не получает полный valid.
