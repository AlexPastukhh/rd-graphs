# Исторические handoff/snapshot RDG — только аудит

Все существовавшие здесь `before*`, `CHECKPOINT.md`, `PROPOSAL.md`, `SCOPE.md` и снимки старых README относятся к **состоянию на момент передачи задач**. Их заголовки «актуальный», старые версии 1.x–2.x, таблицы API/прав или отчёты тестов *не* соответствуют автоматически нынешней реализации. **Их байты намеренно не изменялись**, чтобы не переписывать первичные материалы; отсутствие баннера внутри snapshot не даёт ему нормативного статуса. Новый чат не должен стартовать из handoff, пока не прочитает действующие [контракт](../guides/RDG-ACTIVE-CONTRACT.md) и [операционный регламент](../guides/RDG-OPERATIONS.md).

**Fortis handoffs 2026-10-30, 2026-10-31 и 2026-11-01** — только исторические снимки provisioning/design/preflight и их тогдашних next steps. Их статусы `NOT DEPLOYED`, `NOT STARTED`, `NO-GO` и команды старого cutover относятся к датам снимков и superseded. Текущее Fortis состояние и единственный актуальный путь: [Fortis current state](../guides/FORTIS-APPROVALS-SECURE-DEVELOPMENT.md). Не повторять из handoffs GO-1/GO-2/GO-3 или старые P1/P2 scripts.
