# Историческая схема внешней подписи RDG — отменена

**Superseded · не использовать как инструкцию.** Схема Ed25519 была экспериментальным дополнительным барьером, но пользователь уточнил: штатная запись committed D сама означает принятие. Публичный ключ, receipt и параметры approval-request/approval-receipt больше не нужны; они удалены из writer.

Актуальная гарантия: правильное committed D с соответствующим материальным событием выбора/пересмотра, настоящими R/driver/T1/QRPE, проверкой revision, history, path, journal и readback. Атрибуция by=user не заменяет проверки реального смысла принятого решения. Шаблон и Context не могут автоматически распоряжаться writer. Committed не равно implemented или verified achieved.

Действующее руководство: RDG-V7-WORKING-GRAPHS.md. Это лишь историческое пояснение, не второй нормативный owner.
