## Краткий результат

Пакет реализован в существующем rd-graphs. Viewer 1.2.0 / Loader 2.4.0 показывает широкие TM-планы на общей карте; Unit-графы открываются из соответствующих R, включая дальнейшую глубину. Подготовлены 78 графов, из них 53 Unit; все 38 исходных 2D Units имеют отдельные графы с прежними IDs.

Writer проверяет пакет связанных файлов до записи, поддерживает создание графов, типизированное применение готового модуля, revisions, повтор запроса, восстановление и пересмотр D с сохранением прежнего ответа. Общая карта не строит обходные стрелки через скрытые Units; «Показать все графы» отсутствует по указанию пользователя.

**Проверено:** 132 автоматические проверки без ошибок; реальный runtime Helper — обновление прежних IDs, сохранение посторонних записей, no-op повтор; изолированный headless Edge на Windows — карта, скрытие Units, вложенная навигация, возврат, прямой Unit и общий источник. Хеши четырёх доставляемых файлов Windows совпали с Repo. 11 изменённых helper records опубликованы и прочитаны обратно; два прежних текста совпадают без изменения.

**Осталось действие в пользовательском браузере:** обновить внешние зависимости Tampermonkey/страницу, импортировать актуальный payload поверх прежних 13 IDs и использовать раскрытый bootstrap в новом чате. Установленная память Helper и фактический новый пользовательский чат не проверены. Headless Edge работал с новым кодом в отдельном чистом профиле, без установленного пользовательского Tampermonkey.

Новые проверки покрывают 38 Unit-источников, вложенные переходы, dry-run без создания файлов, replay, конфликт transactionId/revision, неверный owner/source version/bindings, межфайловый цикл, ревизию D, прерывание и отказ восстановления при чужой правке.

Первый общий прогон обнаружил 13 старых ожиданий о количестве/размере графов, видимости Units и версии Viewer. Ожидания приведены к новой функциональности, проверки источников/истории/identity сохранены. Изолированный Edge подтвердил реальные DOM-переходы отдельно от Node-модели DOM.

Авторские `.md` и payload согласованы. Builder сохраняет createdAt, обновляет updatedAt при изменении текста и не меняет его при повторной сборке. Четыре верхнеуровневых промпта раскрываются настоящим resolver без незакрытых references: bootstrap — 34 521 символ, PLAN — 28 156, COMMIT — 22 315, CROSSCUT — 21 050.

Каждый изменённый файл записан по актуальному SHA и точно прочитан обратно. Два неизменённых текста — repository/value — проверены без публикации заново.
