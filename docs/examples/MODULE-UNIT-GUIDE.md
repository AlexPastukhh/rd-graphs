# Модуль и Unit: графы по одному Requirement

Target Module — целый план для своей цели R: конкретный способ D и необходимые под-R.
Unit использует ту же механику, но решает более узкую задачу. Размер файла и число узлов не определяют масштаб.

Откройте graphs/examples/reference-module-units/graph.json.
На общей карте это широкий TM. Его R «Описать наблюдаемый результат» открывает reference-unit-direct:
прямой способ D, без искусственного дальнейшего разбиения.
R «Проработать состояние и переходы» открывает reference-unit-split:
разбиение полезно, потому что состояния и переходы требуют самостоятельных ответов.
Из него открываются reference-unit-states и reference-unit-transitions; «Уровень выше» возвращает назад.

Все пять графов — подготовленные учебные способы. Ни одно D не принято в реальном проекте.
Стрелки готового состава означают «может ввести под-R при выборе этого способа», а не выполненный план.
Unit-графы скрыты на общей карте и доступны по соответствующим R. Режим «Показать все графы» отсутствует.

Полный источник хранится один раз в широком графе; Unit-графы используют ссылку на него.
Цель Unit имеет тот же ID и ссылку на владельца R в родительском графе.
